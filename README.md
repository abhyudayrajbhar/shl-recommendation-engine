# SHL Assessment Recommendation Engine

This project is a solution for the SHL AI Research Intern take-home assignment.  
It provides a system to recommend SHL assessments based on a given job description or query.

## Project Overview

The system consists of:
- A recommendation engine using sentence embeddings.
- A Flask-based API with endpoints for health check and recommendations.
- A Streamlit-based frontend for interactive usage.

## Features

- `/health` API endpoint to check service status.
- `/recommend` API endpoint to get top 10 assessment recommendations.
- Web UI to input queries and view recommendations.
- Clean, scalable, and lightweight design.

## Tech Stack

- Python
- Flask
- Streamlit
- Pandas
- Sentence Transformers (`all-MiniLM-L6-v2`)
- scikit-learn
